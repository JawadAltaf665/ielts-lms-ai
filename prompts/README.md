# Prompts

AI prompt templates and evaluation prompts for **IELTS LMS AI**.

## Purpose

This directory will hold the versioned prompt templates that drive the platform's AI features — automated evaluation of Writing and Speaking, the AI Tutor, feedback generation, and content assistance. Centralizing prompts makes them reviewable, testable, and auditable.

## Planned Scope

- Writing evaluation prompts aligned with IELTS band descriptors.
- Speaking evaluation prompts and rubrics.
- AI Tutor conversation and guidance prompts.
- Feedback and explanation generation prompts.
- Grammar, vocabulary, and sentence-builder assistance prompts.
- Prompt versioning, changelog, and evaluation notes.

## Conventions

- Treat prompts as source: review changes, version them, and document intent.
- Keep model-specific details separate from prompt content where possible.
- Never embed secrets or API keys in prompt files.
- Align evaluation prompts with official IELTS scoring criteria.

## Status

Empty by design. Prompt templates will be added during the AI Evaluation phase. The AI evaluation architecture is documented under [`/docs`](../docs).
