# Scripts

Automation and developer tooling for **IELTS LMS AI**.

## Purpose

This directory will hold utility scripts that support development, build, testing, database management, and operational tasks. Scripts keep repetitive workflows consistent and repeatable across the team and CI.

## Planned Scope

- Environment bootstrap and setup scripts.
- Database management helpers (migrate, seed, reset).
- Build, lint, and test convenience scripts.
- Data import/export and maintenance utilities.
- CI/CD helper scripts.

## Conventions

- Prefer cross-platform scripts where possible.
- Keep shell scripts POSIX-compatible (`*.sh`) and Windows scripts as `*.ps1` / `*.cmd`.
- Document each script's purpose and usage at the top of the file.

## Status

Empty by design. No scripts exist yet — the project is in the Architecture & Planning phase.
