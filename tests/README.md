# Tests

Cross-cutting and end-to-end test assets for **IELTS LMS AI**.

## Purpose

This directory will hold tests that span multiple components or exercise the platform as a whole — end-to-end (E2E) flows, integration suites, contract tests, and performance/load tests. Unit tests generally live alongside the code they cover within `frontend/` and `backend/`.

## Planned Scope

- End-to-end user journey tests (learner and admin flows).
- Cross-service integration tests.
- API contract tests.
- Performance and load testing scenarios.
- Multi-tenancy isolation tests.
- Test data fixtures and helpers shared across suites.

## Planned Technology

- Frontend/E2E tooling (TBD — e.g., Playwright/Cypress)
- Backend integration testing aligned with .NET
- Load testing tooling (TBD)

## Status

Empty by design. No tests exist yet — the project is in the Architecture & Planning phase.
