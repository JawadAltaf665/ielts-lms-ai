# Assets

Shared static assets for **IELTS LMS AI**.

## Purpose

This directory will hold static, non-code assets shared across the project — branding, design resources, and reference media that are not tied to a single application build.

## Planned Scope

- Logos, icons, and brand assets.
- Design references, style guides, and mockups.
- Diagrams and illustrations used in documentation.
- Sample/reference media for Listening and Speaking (non-production).

## Conventions

- Keep binary assets optimized and reasonably sized.
- Prefer vector formats (SVG) for logos and icons where possible.
- Do not store production learner content or copyrighted exam material here.

## Status

Empty by design. Assets will be added as branding and design work progresses.
