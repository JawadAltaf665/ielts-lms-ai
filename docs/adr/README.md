## How to Add an ADR

1. Copy [`0000-template.md`](./0000-template.md).
2. Name it with the next sequential number and a short slug (e.g., `0001-choose-multi-tenancy-model.md`).
3. Fill in the sections.
4. Add it to the index above.

## Conventions

- ADRs are immutable once accepted. To change a decision, add a new ADR that supersedes the old one.
- Reference superseded ADRs explicitly.
