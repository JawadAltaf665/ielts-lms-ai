# Frontend

The web client application for **IELTS LMS AI**.

## Purpose

This directory will contain the user-facing web application through which students, teachers, institute administrators, and platform operators interact with the platform. It is responsible for presentation, client-side state, and communication with the backend API.

## Planned Scope

- Learner experiences for Reading, Writing, Listening, Speaking, Grammar, Vocabulary, and Sentence Builder.
- AI Tutor and Daily Learning interfaces.
- Mock test delivery and results/band-score visualization.
- Progress tracking and analytics dashboards.
- Tenant-aware theming and role-based UI (RBAC).
- Subscription and account management screens.

## Planned Technology

- React (TypeScript)
- Component library and design system (TBD)
- Client-side routing and state management (TBD)

## Status

Empty by design. No application code exists yet — the project is in the Architecture & Planning phase. Scaffolding will follow once the architecture documents are complete.
